UIO Sequence Generation

14 novel algorithms for constructing Unique Input/Output (UIO) sequences in deterministic finite state machines — genetic, vectorised and CUDA-parallel variants — validated across 245 FSMs.

This project tackles a classic problem in conformance testing: finding a Unique Input/Output (UIO) sequence for every state of a deterministic finite state machine (FSM) — a short input sequence whose output signature identifies that state unambiguously. UIO sequences underpin protocol and hardware testing, but computing them for large machines is computationally hard. I designed and implemented 14 novel algorithms — including population-based genetic variants — and benchmarked them against baseline methods on large machines, achieving up to 5× speedup on FSMs with 2,500+ states. The full methodology and findings are documented in a 12,000-word technical report (PDF).

Key Features:
  • 14 Novel Algorithms: Designed and implemented fourteen algorithms for UIO sequence construction, including genetic/evolutionary variants that evolve candidate sequences as populations of chromosomes, scored against the full state set in a single pass.
  • Vectorised NumPy/PyTorch Core: Replaced per-state Python loops with vectorised tensor operations, eliminating interpreter overhead and enabling batch chromosome evaluation across thousands of states simultaneously.
  • Parallel & GPU Variants: Engineered multithreaded versions of every algorithm using thread pools, shared work queues and lock-based synchronisation, plus CUDA acceleration via PyTorch, to exploit multi-core CPU and GPU architectures.
  • Comprehensive Empirical Study: Evaluated all methods across 245 FSMs of up to 15,000 states and 1,000 inputs/outputs, isolating scalability with respect to states, inputs and outputs independently.
  • Results: Up to 5× speedup over baseline methods on large FSMs, with the findings and methodology documented in a 12,000-word technical report.
