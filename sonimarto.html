Sonimarto is a production SaaS platform that helps e-commerce resellers buy low and sell high with confidence. Users upload product photos and titles, and the platform's AI agents identify each item, match it across more than twenty marketplace APIs, and return a defensible estimated market value — backed by the underlying listings and a transparent confidence score. Originally prototyped as a Python command-line tool, it has since grown into a fully deployed web platform serving real users at sonimarto.com.

Key Features:
  • Eight AI Agents, Five LLM Providers: A multi-agent pipeline of specialised LLM agents — item matcher, photo identifier, description generator, brand specialist, title cleaner, quality assessor and more — classifies and enriches every product. Provider-aware fallback chains across five LLM providers, with curated prompt libraries and stricter-prompt retries, keep results stable even when a provider fails.
  • Multi-Marketplace Integration: 20 REST APIs alongside XML-based and custom-protocol services, all normalised through a single adapter layer — with fallback data providers that keep data flowing when a marketplace is unavailable.
  • Statistical Valuation Engine: Sold-anchored quartile distributions, an accuracy-penalised matcher that filters ambiguous price histories, per-marketplace fee models and a self-improving sale-duration predictor produce estimates with a transparent, data-backed confidence score.
  • SaaS Billing, Quotas & Analytics: Stripe-powered subscription tiers with a credits system for API-heavy searches, in-app notifications, and privacy-first first-party analytics (cookie-free, hashed IPs) with scroll, heatmap and dwell-time insights surfaced in a live admin dashboard.
  • Production Deployment: Dockerised on a hardened single-host droplet — five Gunicorn workers behind nginx load balancing, Redis caching, SQLite storage, health checks with automatic restart, rate limiting and uptime monitoring.
Technologies & Skills:
  • Languages: Python, JavaScript, HTML/CSS
  • Backend: FastAPI, Gunicorn, REST API design
  • AI: Multi-agent LLM pipelines, prompt engineering, computer vision
  • Integrations: 20+ marketplace & data APIs (REST, XML and custom protocols)
  • Payments & Authentication: Stripe subscriptions, Google OAuth, WebAuthn
  • Data: SQLite, Redis caching
  • DevOps: Docker, nginx, rate limiting, health checks, uptime monitoring
  • Status: Live in production at sonimarto.com
